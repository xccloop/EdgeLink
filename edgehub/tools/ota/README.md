# Hub OTA验签支持

这些文件是Hub独立使用的镜像v2定义、分块验签接口、CRC和固定公钥。构建不引用Node目录。

SHA-256和micro-ecc位于相邻的`../crypto/`，包含固定上游版本、许可证和本地修正记录。Hub不保存私钥。

与Node的协议约定：256字节头，算法1=P-256/SHA-256，签名为大端r||s共64字节，覆盖签名字段清零后的前252字节头和完整应用，头CRC最后生成。

两个项目独立保存格式定义和同一个公钥。以后改变镜像格式、算法或信任公钥时，需要明确同步两边并运行各自回归；不能只更换一边。当前公钥C数组和PEM与Node部署公钥一致。

`ota_image.h`和`flash_layout.h`在此只用于识别Node固件格式和地址范围，不使Hub依赖Node工程或其构建产物。
