# GD32F10x firmware library placement

Copy the library's `Libraries` directory contents here so the paths are:

- `firmware/CMSIS/GD32F10x/Include/gd32f10x.h`
- `firmware/GD32F10x_standard_peripheral/Include/`
- `firmware/GD32F10x_standard_peripheral/Source/`

The VS Code IntelliSense and Makefile paths already point to these locations.
