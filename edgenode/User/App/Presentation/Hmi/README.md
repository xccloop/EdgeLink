# HMI 层

320×240、深色英文界面：HOME 显示温度、Wi-Fi 状态、SSID 和节点 IP；LINKS 显示 TCP/CAN 最近观测状态；LOG 显示最新一条日志并自动换行。底部 28 像素为导航条，当前页实心高亮，候选页描边，确认后才切换正文。

本目录实现显示逻辑，**没有接入任务、队列、中断、main 或 Startup**。固件原有启动行为保持不变，当前运行程序不会主动显示这些页面。

## 分层

- `Widget`：普通 RGB565 图片描述、矩形/文字场景描述、480 字节 ASCII 5×7 字库。字号通过整数放大实现，包含大小写、数字、标点和摄氏度圆圈。
- `Render`：按场景合成一行，将 RGB565 转成高字节在前，调用已有 `display_render_span()`。BUSY 保留行号，错误锁存；空闲时继续服务 Buffer，完成末尾发送。
- `Page`：三页坐标、状态配色、温度格式、日志换行和导航样式。仅构造场景，不访问 IPS、SPI 或 DMA。
- `Control`：持有最新数据副本、当前页、候选页和待刷新区域。绘制期间数据更新不修改正在读取的场景，下次空闲时合并刷新。

原有两个 DMA 行缓冲及其状态机不变。Render 另有 **640 字节 CPU 合成工作区**，该工作区同步复制进 Buffer 后就可重用，不作为第三个 DMA 槽。没有全屏缓存、动态内存或阻塞等帧循环。

## 对外调用

包含 `Presentation/Hmi/Control/hmi_control.h`。所有接口由**同一个执行上下文串行调用**；不能直接从 ISR 或多个业务任务并发调用。将来接任务时，由该任务接收外部消息，再更新 HMI。

| 接口 | 约定 |
| --- | --- |
| `hmi_init(node_id)` | 外部已成功初始化 IPS 和 Buffer 后调用一次；重复调用无操作，不清空 DMA 或重置页面 |
| `hmi_set_view_data(&data)` | 复制完整显示快照；成功返回 1，未初始化、空指针或非法链路枚举返回 0；不会持有调用方字符串指针 |
| `hmi_key_event(key)` | 已消抖的一次 PREVIOUS/NEXT/CONFIRM 事件；不读取 GPIO，不实现消抖或长按 |
| `hmi_service()` | 周期调用；每次最多提交一行，空闲时仍推进 Buffer；返回 0 表示未初始化或错误锁存 |
| `hmi_refresh()` | 显式解除错误锁存并请求整屏重画；不停止当前绘制、不复位外设；活动绘制结束后再重画 |
| `hmi_current_page()` / `hmi_selected_page()` | 查询逻辑当前页和候选页；物理显示可能仍在逐行更新 |

`hmi_view_data_t` 由调用方维护完整快照，更新一个字段时保留其他字段，再提交整份数据。

- `temperature_deci_c`：有符号整数，单位 0.1 °C，246 是 24.6 °C，-1 是 -0.1 °C；`temperature_valid == 0` 显示 `--.-`。已有采集值需要由未来接入者按其 `temperature_scale` 换算，HMI 不主动采样。
- `wifi_ssid[33]`：连接的 Wi-Fi 名称，最多 32 字节；`local_ip[16]`：节点自身 IPv4 文本，最多 15 字节。Wi-Fi 为 UNKNOWN/OFFLINE 时界面显示 `--`，避免展示旧连接地址。
- `wifi_state`、`tcp_state`、`can_state`：UNKNOWN/ONLINE/OFFLINE，只显示调用方最近观测，不自行探测、超时或推断。CAN 未确认通信时应传 UNKNOWN。
- `latest_log[257]`：最新一条日志，最多保存 256 字节，自动换行，每行 24 字、最多 6 行，显示不下时加 `...`；更新会覆盖旧日志区域。空日志显示 `No log received.`。
- `log_uptime_seconds`：该日志产生时的启动时长，以 `小时:分:秒` 显示；不是实时时钟，小时可以超过 24。
- 英文/ASCII 为当前字库范围，非 ASCII 字节替换成 `?`；中文 SSID 暂不支持字形显示。日志保留换行，制表符和回车显示为空格。固定数组不终止时仍按容量截断。

示意调用如下，仅说明未来接入位置，没有新增任务代码：

```c
/* 外部：先检查 ips_init() 和 display_buffer_init() 的成功结果。 */
hmi_init(board_id);

/* 外部维护的快照，温度和网络结果均来自原有业务，不在HMI中获取。 */
hmi_set_view_data(&view_data);
hmi_key_event(HMI_KEY_NEXT);    /* 选中候选项，正文仍是旧页面 */
hmi_key_event(HMI_KEY_CONFIRM); /* 请求进入候选页 */

/* 外部周期驱动，即使没有新数据也必须继续调用。 */
if(hmi_service() == 0U)
{
    /* 外部记录错误/排查显示硬件，决定重试时调用hmi_refresh()。 */
}
```

## 异步完成和刷新边界

当前 Buffer 没有非阻塞“发送队列全部排空”查询。`hmi_render_busy() == 0` **只保证源像素已复制到 Buffer**，因此可以重建场景或释放图片源；不代表最后的 DMA 已完成，不能停止 `hmi_service()`。持续服务会推进最后的 READY 行，并报告晚到的 DMA 错误。

切页不会取消已有行，而是先提交完旧场景，再按原有 FIFO 提交新场景。导航只重画 212–239 行，正文重画 29–211 行，公共头部重画 0–28 行；多个待刷新区域合并成连续行范围。更新相同数据不额外重画。不是整屏双缓冲交换，物理屏幕可能看见逐行刷新。

直接调用 `hmi_render_widget()` 时保持原有图片提交入口，但像素现在明确为**普通 RGB565 数值**，不能预交换字节。描述结构会复制，像素数组须在 `hmi_render_busy()` 变 0 前只读有效。不要让外部绘制代码和 Control 同时争用 Render/Buffer。

## 验证

仓库根目录运行 `edgenode/tests/hmi/run.ps1`，需要主机 GCC。测试链接真实 Buffer 和模拟 IPS，检查循环选页、确认、导航局部刷新、未终止字符串、长日志截断、短日志覆盖、绘制中更新快照、温度边界、RGB565、裁剪、BUSY、DMA 缓冲所有权、错误恢复和尾行发送。主机帧缓存仅用于测试，不编入固件。

测试输出 PPM 位图至 `edgenode/build/hmi-tests/`。ARM 编译命令仍是 `mingw32-make -C edgenode -j2`；由于暂未接任务，正常链接会垃圾回收未使用的 HMI 函数。另做保留 HMI 入口的链接验证，新增静态 RAM 约 4.2 KiB（含原本未使用而被移除的 Buffer），保留版本 BSS 为 17,620 字节。

主机测试、编译和位图检查不等于实屏验收。本阶段没有烧录，ST7789 色彩、方向、SPI/DMA 时序、真实刷新速度和任务栈余量仍待后续接入验证。
